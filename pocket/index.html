    LAYER 01 / 机身

    竖版机身 · 像素外壳

    按 1989 年 DMG-01 的布局摆：屏幕在上，十字键在左下、A / B 斜排在右下，SELECT / START 居中，右下角是扬声器孔。机身走像素风——直角、3px 硬描边、纯色块、零模糊阴影，没有塑料渐变；屏幕是暗橄榄液晶（#555e4b / #10150b，取自面板截图的实测采样，饱和度约 20%），只留极淡点阵和一道斜光。

    LAYER 02 / 卡带

    插卡就玩

    顶部卡带口点一下选文件，屏里就进卡带页。玩家看不到内部术语——导入进来能跑的都叫卡带。三个原创游戏是内置卡带；老游戏用你自己的卡带，核心走 attachCore()。

    LAYER 03 / 金手指

    存档 → 酒馆世界书

    首次开启弹窗询问；确认后调用脚本内接的 callOpeningModel 风格 API 转写，生成 world_info.entries 条目：训练家、同行、配招、道具、羁绊与特殊事件。条目可折叠、可改、可启用、可导出。

    LAYER 04 / 美化

    moon-skin v1

    一套 JSON 定义全部配色，含屏幕液晶色调。内置黑粉默认 + 三个从你的 My Boy 美化 APK 抽色的皮肤；图案走本机导入槽，不打包第三方素材。tools/apk-skin-extract.mjs 可继续转更多 APK。

    关于你上传的目录：ROM 是 32 MB 汉化改版（POKEMON EMER / BPEE），装载器已按真实头部重写，32 MB 也能过。目录里的模拟器是 VBA 的 exe、My Boy / GBA4iOS / Delta 的 APK 与 IPA、以及 44670.org/gba 的网页版——前三种是编译好的程序，没有能在网页里直接搬的 JS 源码；那个网页版是 vba-next-wasm（VBA-Next 编译成 WASM，GPL），要用就按它的许可证接进来，正好走 attachCore()。
    MODE / TAVERN OS

    酒馆模式下，宽屏显示月相、角色建档、世界书、时间线、沉浸模式与街机入口；拨到街机模式，屏幕直接切成模拟器启动菜单。切换不会中断正在运行的游戏与存档。

    接入规范 接进 4.8.22 的入口 / 世界书与美化格式

    ① 世界书 = 酒馆 world_info.entries

    条目字段直接复用酒馆格式（key / keysecondary / comment / content / disable / constant / order / position 等），导出即可被酒馆世界书导入。存档键按聊天隔离。

    // 月相脚本侧：把内接的模型 API 绑进来
MOON_POCKET.bindNarrator((sys,user)=>callOpeningModel("main",sys,user));
MOON_POCKET.enableCheat(true);  // 首次弹窗 → 转写 → 编辑页
MOON_POCKET.attachBridge({ name:"mGBA",
  readSnapshot: async()=>readPartyAndBagFromRAM() });
MOON_POCKET.getInjectedWorldInfo(); // 启用条目 → 剧情注入

    存档桥支持三种来源：模拟器核心的 readSnapshot()、moon-savelog 游戏日志 JSON、以及原始 .sav（做扇区与校验读取，明细仍需核心或日志）。

    ② moon-skin v1 / 美化格式

    一份 JSON 定义全部令牌；assets 可放本机图案的 data URI，只在玩家自己机器里，不随宿主分发。

    { "format":"moon-skin", "version":1,
  "id":"moon.noir-pink", "name":"黑粉 · 默认",
  "tokens":{ "bg":"#100b11", "surface2":"#2a1a2a",
    "accent":"#ff86c2", "lcd":"#555e4b",
    "ink":"#10150b" /* …共 12 项 */ },
  "scanline":0.035, "radius":18, "assets":{} }

    协议沿用 v2：宿主 → 页面 boot / input / pause，页面 → 宿主 ready / launch / save / score；沙箱 iframe 不变，等待框仍只在月相自己发起的长任务里弹。

    本页实际包含什么。 三个原创像素小游戏（自有代码与程序化绘制，可按 CC0 使用）、一个本机 ROM 头部与 SHA-1 校验流程、一套可插拔核心接口、一套世界书转写与编辑逻辑、一套皮肤格式。不含 ROM、模拟器核心、任天堂图像 / 音乐 / 文本，也未使用「宝可梦」作为产品标识。要玩老游戏：自己从合法持有的卡带 dump 出文件 → 插进顶部卡带口 → 接上开源核心。

    关于「古老 / 非商业」。 绿宝石 2004 年首发，著作权仍在保护期。中国著作权法第 24 条合理使用限于个人学习、研究、欣赏；把游戏文件打包进发布物或向公众提供属第 53 条的侵权行为，是否营利不是侵权认定标准。玩家自己 dump 自己玩、写模拟器、做美化配色都不越线；被追责的一直是分发 ROM 的站点与打包第三方素材的发布物。

    GOLDEN LINK / 金手指模式

    把存档里的宝可梦写成世界书？
