# Galgame 攻略系统

## 导入到酒馆助手

请导入仓库中的 `Galgame攻略系统-酒馆助手导入.json`，不要把 `moon-phase.js` 直接选作“脚本库导入”文件。`.js` 是脚本源码；酒馆助手的脚本导入需要 JSON 脚本记录。

在酒馆助手的「脚本库」中选择导入该 JSON。它会创建或更新名为「Galgame攻略系统」的全局脚本，脚本已默认启用。导入后按酒馆助手提示确认并刷新页面。

`moon-phase.js` 是自动更新使用的完整脚本，玩家下载到的就是它。

## 源码结构

仓库里的源码是拆开的（`src/` 下 38 个模块），但**玩家拿到的始终是一个完整脚本**——由 GitHub Actions 在每次改动后自动拼好：

```
src/*.js  ──[ scripts/build.mjs ]──►  moon-phase.js
                                   └─►  Galgame攻略系统-酒馆助手导入.json
```

改动流程：

1. 改 `src/` 里对应的模块（模块表见 [`src/README.md`](src/README.md)）；
2. 本地跑一次 `node scripts/build.mjs`（需要 Node.js），生成 `moon-phase.js` 和导入 JSON；
3. 提交推送。就算第 2 步忘了，`push` 到 `main` 后 Actions 也会自动构建并把产物提交回来。

**不要直接改 `moon-phase.js`**，它下次构建会被覆盖。`scripts/build.mjs --check` 可以只检查产物是否与源码同步（PR 里会跑这个）。

## 更新

面板「更新与帮助 → 🔄 检查版本更新」即可。更新线路是自动兜底的：先走官方直连，8 秒不通自动换国内镜像（jsDelivr / jsDelivr Fastly / ghproxy.net / gh-proxy，整条链路 45 秒封顶），上次能用的线路会被记住；全部连不通时才会弹窗，列出每条线路的失败原因并给出「再试一次 / 换源」。

完整说明（线路顺序、三种提示、失败急救、常见问题、手动更新）见 [`更新说明书.md`](更新说明书.md)；历史版本记录见 [`update.md`](update.md)。

## 回忆画廊与周目结算

重大事件和系统掷出的 1d20=20 彩蛋可在当前聊天中解锁成就；结局条件会先询问玩家，再生成本周目结算卡。画廊、解锁记录和周目记录按聊天分别保存。支持归档的图片保存在浏览器 IndexedDB；如果服务商图片禁止跨域读取，画廊会保留服务链接。

图片生成不会在后台自动发起。需要从「系统选项 → 回忆与影像」选择图片服务并保存设定，再到「角色与存档 → 回忆与周目」打开画廊，手动显影 CG。图片提示词会发送到所选服务；API Key 仅存于本机浏览器。后日谈也由玩家手动启动，可在同一设置页调整目标篇幅。
