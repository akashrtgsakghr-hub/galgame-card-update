# 全局美化包 · 制作文档（v1）

> 适用版本：5.2.0 及以后 · 主题格式 `moontheme/1`
>
> 这份文档是给 **AI** 看的。你不用会写 CSS：把整份文档丢给任意模型（Claude / GPT / DeepSeek / Gemini / 本地模型都行），
> 末尾加一句「我要 XX 风格」，它会吐出一段 JSON；把 JSON 粘回面板就能用。
>
> 你（AI）的任务：**读懂下面的最高指令与字段表，输出一个符合 `moontheme/1` 的 JSON 对象。**
> 只输出 JSON，不要解释，不要代码围栏。

## 1. 最高指令（不许违反）

下面是作者定的 UI 铁律，**原文一字不改**：

```
ui布局严格执行：1.禁黑框与#000，靠1-3%微明度4层背景分层；2.输入框聚焦禁描边，加深双环阴影；3.暗色字重全降40；4.流式打字blur(6px)渐显，120ms且字间错开30ms；5.图标下移0.125em对齐；6.数字锁tabular-nums防抖；7.折叠用Grid 0fr→1fr；8.正文开text-wrap:pretty；9.拖拽弹簧1200/80零回弹，点赞380/18微弹；10.复制对勾2.5s自隐。
```

### 逐条落地：哪些归你管，哪些你别碰

| # | 条款 | 在这份主题里怎么落实 | 你（AI）要做的 |
| --- | --- | --- | --- |
| 1 | 禁黑框与 #000，靠 1-3% 微明度 4 层背景分层 | `l0/l1/l2/l3` 四层底色，相邻两层明度差 1%~3%；`line/line2` 是发丝线，**不是边框色块** | 给全四层，别把 `l3` 写成 `l2` 的复读；任何 token 都不要写 `#000000` / `rgba(0,0,0,x)` |
| 2 | 输入框聚焦禁描边，加深双环阴影 | 脚本已接管：聚焦时 `border-color = line2`，双环 = `accent` 一环 + `shadow` 一环 | 只要保证 `accent` 与 `l2` 对比 ≥ 3:1，环才看得见；**不要**在 `css` 里写 `outline` |
| 3 | 暗色字重全降 40 | 插件在暗色下把字重从 600/400 降到 360/300 | 别在 `css` 里写 `font-weight`（白名单也不收）；`font-family` 别挑 Black/Heavy/Ultra 这类字面 |
| 4 | 流式打字 blur(6px) 渐显，120ms 且字间错开 30ms | 插件行为 | **别碰**：`css` 白名单没有 `animation` / `transition` |
| 5 | 图标下移 0.125em 对齐 | 插件行为 | **别碰**：白名单没有 `margin` / `padding` / `transform` |
| 6 | 数字锁 tabular-nums 防抖 | 插件已锁 | 换字体时确认数字是等宽的（等宽字体或系统 UI 字体都行），别选装饰体 |
| 7 | 折叠用 Grid 0fr→1fr | 插件行为 | **别碰** |
| 8 | 正文开 text-wrap: pretty | 插件已开 | `letter-spacing` 保持在 `0`~`0.02em`，别为了「疏朗」拉到 `0.1em` 以上 |
| 9 | 拖拽弹簧 1200/80 零回弹，点赞 380/18 微弹 | 插件行为 | **别碰** |
| 10 | 复制对勾 2.5s 自隐 | 插件行为 | **别碰** |

一句话总结：**你只能动「颜色」和「材质」，不能动「结构」「节奏」「动效」。**

## 2. 字段表

| 字段 | 类型 | 必填 | 范围 / 取值 | 说明 |
| --- | --- | --- | --- | --- |
| `format` | string | ✅ | 固定 `"moontheme/1"` | 写错直接拒收 |
| `name` | string | ✅ | ≤ 24 字 | 面板列表里显示的名字 |
| `author` | string | | ≤ 24 字 | 署名，可以留空 |
| `desc` | string | | ≤ 120 字 | 一句话说清这套皮的气质 |
| `tokens` | object | ✅ | 见下 | 颜色与圆角 |
| `images` | object | | 见 §4 | 素材，最多 3 个槽 |
| `css` | string | | 见 §5 | 额外声明，只作用于面板本体 |

### 2.1 `tokens`

| 键 | 语义 | 建议 | 硬性要求 |
| --- | --- | --- | --- |
| `l0` | 最底层（面板最暗处） | 明度 6%~10% | 不能是纯黑 |
| `l1` | 第二层（卡片衬底） | 比 `l0` 亮 1%~3% | 比 `l0` 亮 |
| `l2` | 第三层（正文落在这一层） | 比 `l1` 亮 1%~3% | 比 `l1` 亮 |
| `l3` | 第四层（输入框、浮起元素） | 比 `l2` 亮 1%~3% | 比 `l2` 亮 |
| `fg` | 主文字 | 对比 `l2` ≥ 7:1 | ≥ 7:1（不够会被自动抬亮） |
| `fg2` | 次文字 | 对比 `l2` ≥ 4.5:1 | ≥ 4.5:1 |
| `fg3` | 弱文字 / 占位符 | 对比 `l2` ≥ 3:1 | ≥ 3:1 |
| `accent` | 强调色（按钮、聚焦环、进度） | 面积 ≤ 5% | 与 `l2` ≥ 3:1 |
| `accent2` | 强调高光（标题、hover） | 通常比 `accent` 亮一档 | 与 `l2` ≥ 4.5:1 |
| `line` | 发丝线（分隔、输入框边） | `rgba(文字色, .10~.16)` | 别用实色 |
| `line2` | 强发丝线（面板外框、hover 边） | `rgba(文字色, .24~.32)` | 别用实色 |
| `shadow` | 投影色 | `rgba(最底层色, .6~.8)` | 带色相，别用纯黑 |
| `radius` | 圆角（px） | 12~18 | 0~24，超出会被夹到边界 |

## 3. 配色算法（照这个算，一次就过）

不用凭感觉挑色，按下面五步走：

**第一步：定色相**
选一个主色相 `H`（0~360），饱和度压到 `8%~18%`——插件是暗色界面，高饱和会刺眼。

**第二步：铺四层底**
保持 `H` 和 `S` 不变，只动明度 `L`：

```
l0 = hsl(H, S, 8%)
l1 = hsl(H, S, 10%)
l2 = hsl(H, S, 12%)
l3 = hsl(H, S, 14%)
```

相邻差 2%，正好落在铁律一的 1%~3% 区间。浅色主题是例外：`l0=95% → l3=89%`，反过来排。

**第三步：定文字**
不要用纯白。文字也带一点主色相：

```
fg  = hsl(H, S×0.4, 93%)     ← 对比 l2 通常在 9:1 以上
fg2 = hsl(H, S×0.4, 74%)
fg3 = hsl(H, S×0.4, 56%)
```

**第四步：定强调**
强调色可以跳色相（互补或邻近 30°），这是唯一允许高饱和的地方：

```
accent  = hsl(H+30, 45%, 62%)
accent2 = hsl(H+30, 55%, 78%)
```

**第五步：算对比度，不合格就调**
相对亮度：

```
c = 通道值/255；若 c ≤ 0.03928 则 c/12.92，否则 ((c+0.055)/1.055)^2.4
Lum = 0.2126R + 0.7152G + 0.0722B
对比度 = (亮者+0.05) / (暗者+0.05)
```

`fg` 对 `l2` 不足 7:1 就把 `fg` 的明度往上推，直到够为止。

## 4. 素材（贴图）

### 4.1 格式

只收内联 data URL：

```
data:image/webp;base64,<...>
data:image/png;base64,<...>
data:image/jpeg;base64,<...>
```

**外链一律拒收**（`http://`、`https://`、`file://`、相对路径都不行）。原因很实在：酒馆里的脚本不该在你不知情的时候向第三方发请求。

### 4.2 三个槽

| 槽 | 铺在哪 | 建议 |
| --- | --- | --- |
| `panel` | 整个面板底 | 有横向纹理的材质图最好（丝缎、纸、贝母） |
| `card` | 卡片内衬 | 可选，不给就用纯色层 |
| `bar` | 面板里的状态条 | 可选，通常给同一张图压得更暗 |

每个槽的写法：

```json
"panel": {
  "src": "data:image/webp;base64,UklGR...",
  "opacity": 0.6,
  "blend": "soft-light",
  "size": "cover",
  "position": "center"
}
```

| 键 | 默认 | 取值 |
| --- | --- | --- |
| `opacity` | 0.55 | 0.05 ~ 1。**越高图越清楚，但字也越难读** |
| `blend` | `normal` | `normal` / `soft-light` / `overlay` / `screen` / `multiply` / `luminosity` |
| `size` | `cover` | `cover` / `contain` / `auto` / `100% 100%` |
| `position` | `center` | 任意 CSS background-position |

### 4.3 体积上限

- 单张：解码后 ≤ **320KB**
- 三张合计：≤ **900KB**

超了会被丢掉，并在导入结果里告诉你哪张超了。

### 4.4 没有素材怎么办

**别编。** 没有图就把 `images` 写成 `{}`，只给颜色——一套配色对味的纯色皮，比一张糊住字的图好看得多。

也可以引用插件内置的第一批素材（玩家侧不需要额外下载）：

```
"src": "builtin:nacreNight"   // 鲍鱼贝内壁（暗）
"src": "builtin:paperNight"   // 压暗的丝缎横纹
"src": "builtin:nacreDay"     // 珠光纸（浅，适合压到低透明度当高光）
"src": "builtin:paperDay"     // 冷白丝缎（浅）
"src": "builtin:coverNight"   // 双扇贝（暗）
"src": "builtin:coverDay"     // 双扇贝（浅）
```

> 注意：`builtin:` 只有在本插件里有效。你要把主题发给别人，先导出一次，导出会把内置图换成真图。

### 4.5 面板的「机身」也会跟着换

除了底色，脚本还会把这些一起换掉：卡片的衬底、液晶屏外框、页签的选中态、
按钮的悬停、输入框的聚焦环、弹窗的描边。它们各自绑在 `l0~l3` / `accent` / `line2` 上，
所以只要四层排对，整机就是一套的，不会出现「底换了、边框还是粉的」。

素材方面：给了 `panel` 又没给 `card` 时，同一张图会以很低的量（约 8%）垫进卡片里。
只靠缝隙露一点材质，等于没换。

### 4.6 素材与文字的关系

脚本会在素材上面盖一层由 `l1`/`l2` 组成的压暗层，透明度跟着 `opacity` 反着走：
**`opacity` 越高，压暗层越薄，图越清楚，文字越吃力。**

经验值：

- 丝缎 / 纸纹（细密、低对比）：`0.5 ~ 0.7`，`soft-light`
- 贝母 / 珠光（有明显明暗起伏）：`0.3 ~ 0.5`，`soft-light`
- 照片（有主体、有细节）：`0.12 ~ 0.25`，`multiply` 或 `luminosity`

## 5. `css` 字段（可选）

只能写**面板本体**的声明，会被塞进 `#moon-phase-panel { … }`。

允许的属性和值（白名单）：

```
border-radius  box-shadow  backdrop-filter  -webkit-backdrop-filter
background-blend-mode  letter-spacing  font-family  text-shadow
border-width  border-style  filter
```

出现 `@`、`url(`、尖括号、`expression`、`javascript:` 的，整段不收。

```json
"css": "backdrop-filter:blur(3px) saturate(1.05);letter-spacing:.01em"
```

**不要**在这里写 `color`、`background`、`font-weight`、`position`、`animation`——这些位置脚本自己管，写了也不会生效。

## 6. 输出前自检（逐条打勾）

1. `format` 是 `"moontheme/1"`。
2. `tokens` 里 `l0/l1/l2/l3` 四层都在，明度逐层变亮，相邻差 1%~3%。
3. 全文没有 `#000000`、`#000`、`rgba(0,0,0,…)`、`black`。
4. 没有 `#ffffff`、`#fff`、`white`（纯白在暗色界面上会先跳出来）。
5. `fg` 对 `l2` ≥ 7:1，`fg2` ≥ 4.5:1，`fg3` ≥ 3:1。
6. `accent` 对 `l2` ≥ 3:1，且只占很小面积（别拿它当背景）。
7. `line` / `line2` 是带透明度的 rgba，不是实色。
8. `shadow` 带色相（用 `l0` 的 rgb 加透明度），不是纯黑。
9. `radius` 在 0~24。
10. `images` 里如果有 `src`，是 `data:image/…;base64,` 或 `builtin:xxx`，没有 http 链接。
11. 素材单张 ≤ 320KB、合计 ≤ 900KB。
12. `css` 只用了白名单属性。
13. 输出是**一个 JSON 对象**，没有前后解释，没有代码围栏。

## 8. AI 最容易犯的六个错

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 四层写成同一个颜色 | 界面糊成一块，层级全没了 | 每层差 2% 明度 |
| 用纯黑当 `l0` | 违反铁律一，会被自动染色，你设计的层次就变味了 | 用 `hsl(H,S,8%)` |
| `fg` 用了 `#ffffff` | 夜里一块白先跳出来，别的层次都被吃掉 | 明度压到 93% 左右 |
| 强调色铺大面积 | 像廉价皮肤，且对比全乱 | 强调色只占 5% |
| 塞一张照片满铺 | 字全糊了 | `opacity` 降到 0.2 以下，或换 `multiply` |
| 输出带解释和围栏 | 导入框解析失败 | 只输出 JSON |

## 9. 导入

1. 打开插件面板 → **系统选项** → **外观与阅读**
2. 点 **主题包 / 导入**
3. 把 JSON 粘进输入框 → **导入并应用**（也可以点「选文件」直接选 `.json`）
4. 不满意：列表里点 **还原** 回出厂像素皮

导入时会当场验一遍：纯黑会被染成最底层色、对比度不够会把字抬亮、四层明度差不对会提醒你。
**这些都没问题的话，界面不会告诉你任何事——那就是成功了。**
