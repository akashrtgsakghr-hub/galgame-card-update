# v5.17.0 · 多人卡建档：按世界书认人

## 一句话

多人卡不再拿卡名当角色：从世界书条目里认出人名 → 玩家勾选 → 分批判定（AI / 手填 / 掷骰）→ 落档；档案可删，也可以设「永久不再建档」。

## 改了什么

- **卡名退场**：`getCardMode()==='multi'` 时，候选里不再出现卡名（多人卡的卡名多半是剧本名/合集名，拿它建档会立出一个不存在的人）。
- **只读名字**：先用条目标题（comment）与关键词（key）认出人名，并加了一道闸 —— 正文里没提到过、也没有「角色/人物」标记的条目不算人（「魔法学院」「地图」这类设定词不会进候选）。真正的设定正文只在判某个人的时候按名字取，最多 3 条。
- **关键词触发补档**：自动建档时，多人卡会把「这一轮正文里点到的世界书角色」也算进新角色（以前只认 Sylveina 标签 / 后台变量，模型漏写就永远进不了档）。
- **分批判定**：一次 4 个，逐批给进度；每个人单独判断「与玩家的关系」再给好感 / 肉体值，理由必须引用设定或开场白。
- **三种填法**：让 AI 判 / 自己填 / 掷骰（2d6，7 点中性，范围 −28..28）。
- **删除与永久排除**：删除先确认「只是删这份，还是以后都不建」；勾永久 → 进当前聊天的排除名单（`moon_char_perm_block_v1`），自动建档 / 手动候选 / 关键词触发三处都会跳过，可在弹窗里一键恢复。
- 新增入口：面板 → 人物档案 → **删除角色档案**；开局适配 → **📖 世界书建档**（多人卡高亮）。
