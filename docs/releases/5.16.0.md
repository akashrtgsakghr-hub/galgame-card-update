# v5.16.0 · 核心换了，地图不用自己先走一遍

- **仿真核心换成 mGBA（MPL-2.0）**：32MB 的改版卡带终于能过「新游戏」——旧核心 44vba 在那里死等，黑屏且没有任何报错。老核心留在 `core/` 里，改 `CORE_PICK` 一行就能切回去对照。
- **核心内存每帧核对**：wasm 堆一扩容，旧的帧缓冲 / 存档区视图就失效，症状是画面突然全黑、存档读出来全是 0，还不报错。现在每帧比一次 buffer 身份，换了就重绑；核心真崩了把异常抬到屏幕上。
- **地图直接出整张**：坐标从卡带存档读、地形从卡带里的地图数据渲染，整条路一次画全。点一下画面开全屏整图，可以点格定目的地让掌机指路。
- **小地图缩到四成面积**：按窗口宽度自适应（桌面约 128×96），标题栏和键帽窄屏同步压薄；画布按窗宽 1:1 重设，任何尺寸下都是硬像素。
- **顶部工具条闲置 4 秒自动下沉**，动一下鼠标或按键立刻回来。
- **触屏细节**：去掉按键的双击缩放延迟，抽屉和弹层滚到头不再带动整页，深色模式下表单控件跟主题一致。
- **卡带本体另附**：这一版脚本不带卡带。新 BT999 卡带里带坐标表，才能出整图地图；旧卡带自动退回手绘模式。
