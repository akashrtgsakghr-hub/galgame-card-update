# v5.15.2 · 正文干净了，心声不再断句

> 5.15 的第三版（5.15.0 掌机整包 → 5.15.1 攻略模式 → 5.15.2 这次）。
> 这一版不加功能，只把上次暴露出来的几处毛刺磨平。

- **正文只留故事**：`[Sylveina|甲|L|+|3]` 这类标签结算完就从消息里删掉，不再渲染成徽章。好感度看状态栏——那里有最终值和本轮变化，正文再来一遍是重复。升级后旧消息里的徽章也会一并消失。
- **心声双通道**：状态块（depth 1）里也写了一份 `[心声|角色名|…]` 的格式说明；`message_received` 处理完就提前注入一次，不再只依赖最末尾那条 depth 0——部分酒馆 / 提示词管理器会把它折叠掉。
- **括号不再断句**：内心话里带括号（「他居然记得（那次礼堂）的事」）以前会在括号处被截断，剩下半句漏在正文里；现在整句收下、正文干净。
- **自检新增【测试9B】**：系统诊断室 → 系统自检，直接列出核心规则 / 状态与标签格式 / 心声提醒三条在不在酒馆的 `extension_prompts` 里、各多少字。把「没注入」和「注入了模型没照做」分开。
- **时钟不再偷偷多走**：同一楼层重复触发时，楼层指纹对清洗敏感，会被当成新楼层再走 10 分钟、回合再 +1；现在指纹先归一（把标签、`s` 占位、后台变量行都抠掉）再比。
- 数值算法一个没动：区间夹紧、阶段系数、情绪骰、周上限全部照旧。
- 回归：全部碰撞测试、酒馆实战改版 21/21 与原版 21/21、心声 16/16、UI 38/38。
