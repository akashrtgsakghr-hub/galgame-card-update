# v5.18.4 · 终幕结算走后台；阶段上限去掉；人终于会离场了

这一版主要做一件事：把「结算」从聊天框搬进后台。终幕、后日谈、副本旁白都由脚本自己调模型写完，结果落进一个**跨对话的档案**——换聊天、换角色卡、换玩家设定，打开还在。顺带把上一版加的关系阶段上限去掉了，也让角色终于能真的离场。

### 终幕结算：不再往聊天框里塞提示词

以前点「结算周目」，脚本会把一大段提示词填进聊天框、自动发送，等主模型演完终幕、写出 `[GalgameEnding]` 标签，正则再把它渲染成报幕卡。问题是这轮演出会把当前对话推到很远，而且你得盯着它跑。

现在：

- 点「结算周目」→ **「后台写终幕」**：脚本自己调模型，先出结算卡（结局名 / 复盘 / 角色独白 / CG 提示词），再写一段 **600~1000 字**的终幕正文，直接弹成报幕卡。
- 报幕卡里多一块可折叠的「📜 终幕正文」，想读点开，不想读不占地方。
- 想让它演在公屏上，弹窗里还有**「写进聊天」**，就是以前那套。
- **后日谈也走后台**：点一下分三章写完，不往聊天里塞几千字；阅读器里可以再选择「写进当前对话」。
- 后台调用优先用你自己填的 API，其次酒馆的静默接口，都没有就跳过——不弹窗打断你。

### 新增「脚本档案」：换聊天也还在

- 终幕结算、副本战绩、结算旁白、后日谈，都存进脚本本体，不跟着对话走。
- 换聊天、换角色卡、换玩家设定，打开面板还能看到这一场是怎么结束的，也能导出 TXT。
- 入口：主菜单 → **脚本档案**（全部），或者副本页底部（只看副本）。
- 「存进脚本」可以关。关掉就只留在当前对话，跟着对话一起走。
- 有上限：每类 60 条、单条正文 12000 字——浏览器给脚本的存储就那么点，写爆了先丢最旧的。

### 关系与演出

- **阶段上限去掉了。** 上一版给每个关系档加了「不得有肢体接触」「不得谈长期承诺」这类禁令。它的假设是「关系从零长起来」——碰到「设定里就是相处三年的兄妹」，就会把老熟人判成越界，还和你自己的世界书正文打架。现在只给数值和阶段名，怎么演以你的设定为准。
- **「在场」回归成事实。** 以前判了离场的角色，下一轮提醒里就没了他，状态卡停在离场那一刻；主要角色还容易被硬拉回来。现在写清了：`true` 是「人就在这个场景」，`false` 是「走了 / 在别处 / 被带走」，**「只是这一轮没说话」不算不在场**。写了 `false`，本轮不能有他的台词动作，下一轮也不能凭空出现——他要回来得有由头。允许一个人连续多轮不在场（独处、分头行动、异地、时间跳跃）。
- **建档先读你的人设。** 以前只在开场白里找证据，你写在人设里的「相处三年」「我们是兄妹」被整段忽略，判定只能给 15~25 分。现在两处人设都读（酒馆的 persona + 本系统的玩家档案），先做一次关系摘要，再按证据定档：亲属 / 一起长大 / 十年以上 65~85；三年以上 50~70；几个月到三年 25~45；只是同事 10~30；真陌生人才 0~10，才走初见骰。同一段关系不会这次给 18、下次给 75。
- **重大转折由 AI 给数值。** 新增 `[转折|角色名|±数值|理由]`：AI 判断这一轮真翻了页（记忆恢复、关系挑明、生死关头），可以自己给分，±30 以内、必须带理由、不占每周好感额度、也不吃事件导演的档位限制。带 3 层冷却，不然它会当常规加分手短。

### 掌机与副本

- **面板上下滑，显示屏不漂了。** 点阵背景和内阴影以前跟文字一起重绘，滚动时慢半拍，看起来像屏在自己游动；现在屏是独立绘制区，点阵挪到背景层，面板高度改用 `svh`（不跟地址栏伸缩），滑到底也不会带着页面一起滚。顺手去掉了按键的 300ms 点击延迟。
- **副本结算旁白走后台。** 点「提交判断，结算」，分数当场算完，旁白由脚本后台写（180~260 字，末尾一句「主神：」评语），不占公屏，在「最近几局」里点「看结算」回看。
