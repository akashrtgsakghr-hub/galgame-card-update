# v5.15.5 · 提示词真的进了酒馆

> 这一版修的是一个从 5.10 就存在、但一直没被发现的根因：**脚本注入的规则压根没送进 prompt**。
> 症状是「自测全绿、模拟数据全绿，实战里 AI 却像不知道格式」——不写心声、不写数值标签。

- **位置参数是错的**：酒馆的 `extension_prompt_types` 只有 `BEFORE_PROMPT(2) / IN_PROMPT(0) / IN_CHAT(1)`，脚本一直传 `4`。拼 prompt 时对未知键只放行 0 和 2，其余整条丢弃且不报错。现在统一落到 0（系统提示区）。
- **注入时机也是错的**：以前挂在 `chat_completion_prompt_ready`，而新版酒馆是 prompt 拼好之后才发这个事件 —— 规则永远晚一轮，第一轮干脆是空的。现在主通道换成 `generation_started`（拼 prompt 之前）。
- **心声那句再贴一条到对话末尾**：等价于预设里 `depth 0` 的系统条目，模型更容易照做。
- **后台静默生成不受污染**：成就命名、小抄重写、摘要这类要 JSON 的请求（`generation_started` 的 `quiet` 轮）会先把注入撤掉，正常轮再注回来。
- **面板能看见到底跑没跑**：角色详情里新增「上一轮（N 楼）：好感度 +1.5 → 14」和「已注入 prompt：5 段 / 7834 字」。没结算时直接区分「AI 这轮没写标签」和「被本周额度挡住」，不用猜。
- **自检【测试9B】升级**：除了列字数，还会点名「位置不合法、会被静默丢弃」的条目。
- 另有 5.15.3 的失败惩罚整活（连败 → 猫娘病毒，12 小时 / 终身三档）、5.15.4 的时间短语与时间线开关，一并合进这一版。
