# v5.18.0 · 主神空间（副本）+ 四维结算

这一版是两个大件：一套能自己加本的「副本」玩法，和一次把四维数值真正跑起来的改造。

### 主神空间 · 副本

- **本子写在世界书里**：新建一个条目，标题写 `副本·深夜便利店`，正文写等级、存活时长、规则和分幕，回面板点「扫描世界书」就认到了。脚本只做引擎，你想加几个本、改几次都不用等脚本更新。
- **规则怪谈的玩法内核**：规则分 `[真]` 和 `[假]`。真的违反了出事；假的**遵守了**才出事——那是上一个死者留下的陷阱。AI 看得到标记、你看不到，你得在副本里自己推，最后在面板上给每条规则勾「真 / 假」，正确率直接算进得分。
- **血条**：你和同行者各 80。轻微违规 −16（扛五下）、中等 −27（扛三下）、严重 −80（BOSS 追上，一击带走、强制退出）。
- **同行者阵亡不是结束**：他会变成幽灵跟着你——能说话、能出主意，但他也在猜，给的情报可能是错的。碰不了任何东西，也挡不了刀。只有你看得见他。
- **存活倒计时**：通关看的是「撑了多久」，不是「聊了多少轮」。条目里写 `存活：一夜` / `3 小时 20 分` / `2 天`，倒计时跟主线时钟同一套：你说一句，时钟走十分钟；AI 写「天亮了」，倒计时直接跳过去。没撑满也能交，按撑到的比例给分。
- **积分经济**：通关得分，失败按等级扣（E −20 到 S −50）。余额不够就扣成负数，之后所有加分路径照常往上加，加到正数为止；负余额期间商城锁着。通了关要等 7 天、失败 3 天才进下一个本——都是**游戏里的时间**，挂机等现实时间没用。
- **输了会被硬塞进下一个本**：冷冻时间走完，下一次 AI 回复前主神直接把你拽进一个新副本，不问你，也会避开刚失败那一个。
- 附 8 个成品本（便利店 / 义庄 / 住院部 / 井 / 末班地铁 / 纸扎铺 / 塔 / 无名旅馆），直接导入就能玩。

### 四维结算

- **肉体和嫉妒终于会动了**：以前注入只教了一种标签，而它默认算好感度，所以另外两维从建档那天起就是死的。现在多了 `[肉体|…]` 和 `[嫉妒|…]`，格式照抄原来的，AI 会自己判断什么时候该写。
- **肉体值正名「欲望」**：它说的是**此刻有多想要**，不是身体关系进行到哪一步。所以不用真的发生什么，甚至不用碰到——被撩到、被逼近、闻到对方身上的味道、自己忍不住反复想，都算。它和好感是两条独立的轴：可以讨厌一个人却被撩到，也可以深爱却克制。
- **嫉妒会自己淡**：接回角色档案里本来就有的 `_invidia.每日衰减基数`——大于 0 时，每个**游戏日**降这么多。默认 0，等于和以前完全一样，老存档行为不变。
- **每个关系阶段有了「表现上限」**：以前最常见的出戏是「数值已经封顶了，演出还在往前冲」。现在脚本会把这一档**不许出现的东西**直接写进注入：R3 不许谈长期承诺、不许规划共同的未来；R4 不许求婚、不许用「永远」这类终局措辞；好感周额度用尽的那一轮，会明确要求「把这一场写厚，不写深」。
- 状态卡上「肉体 / 身体状况」的叫法统一成「欲望 / 欲念 / LUST」，和上面的定义对上。
