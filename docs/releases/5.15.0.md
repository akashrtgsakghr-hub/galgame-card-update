# v5.15.0 · 掌机整包：卡带机、小地图、导航、存档跟着聊天走

这一版是 5.8 → 5.15 的累积打包，最大的一件事是把「掌机」做成了一套完整的东西：卡带机在酒馆页面里真的能跑起那张 32 MB 的改版卡带，而且存档存在聊天里。

- **卡带机**：面板里插卡就能玩，屏内直接跑 mGBA 内核，32 MB 卡带装载约 0.1 秒、满 60 FPS。卡带正名为 **BT999变态宝可梦：后宫王内部特供_v9.99魔改汉化版**，封面重排。
- **存档跟聊天走**：存档不再只存在浏览器本地，跟着聊天记录走——换设备、清缓存、重新导入脚本，读到的是同一份档。
- **小地图与导航**：屏里手绘小地图（靠画面拼接，不读内存），配合导航告诉你这一段往哪走；小地图窗与便条窗在 5.14 重做过一遍，窗框用黑粉像素，地图内部保持原色。
- **神宠秘籍**：世界书每一轮都注入提示词，书名固定，翻页不丢。
- **心声标签**：`[心声|角色名|内容]` 落地，写进提示词的位置固定，AI 不再把这句当正文。
- **屏内统一黑粉像素**：插卡页、金手指台、便条、小地图、卡带菜单、屏幕底色统一成一套视觉，不再一块一个样。
- **时间夹回与结局角标**：AI 把时间写飞了会被拉回来并提示；攻略到结局时角标亮起。

> 从这一版开始，仓库同时维护「改版」与「原版」两套产物，原版不含掌机与主题包。
