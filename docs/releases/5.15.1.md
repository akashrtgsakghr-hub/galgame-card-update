# v5.15.1 · 攻略模式：她也有一个不能说出口的系统

> 5.15 的第二版。5.15.0 是掌机整包，这一版在同一套 5.15 里补上攻略系统与签到；
> 5.7–5.15.0 的条目见 README 顶部的更新记录与面板里的更新公告。

- **双版本攻略系统**：角色版与玩家版两套账本、两套货架、两套背包，互相不可见；正文里漏出的系统词会被自动清洗掉。
- **积分商城**：角色侧靠好感增长攒分、玩家侧靠街机/成就/签到攒分；货架每 3 个游戏日刷一次，稀有度抽签。
- **她的秘密任务**：系统给她派活，几回合内没做到会扣分并留下状态，做到了才有奖励。
- **道具与状态**：买来的东西不直接改好感，只变成她身上的「状态」，让 AI 自己在剧情里用出来。
- **签到与大转盘**：每日签到、连签奖励、阶段突破送转盘券，抽出积分/道具/宝石；另有图鉴四栏、限时活动、纪念日与现实活动。
- **像素悬浮窗**：任务板 / 货架 / 背包 / TOKEN 分项统计（世界书、角色卡、用户、系统）四个页签；攻略与反攻略模式都由玩家手动开启。
- **性能**：面板离屏预热，首开 678ms → 47ms；元数据同轮合并落盘，40 回合写盘 236 次 → 41 次。
