# 状态卡美化包 · 制作文档（v2）

> 适用版本：5.3.1 及以后 · 主题格式 `moonstatus/1`
>
> **这份文档不是风格样本，是施工规范 + 验收标准。**
> 卡面是什么颜色、贴什么纸，由玩家决定。
>
> 你（AI）的任务：把玩家想要的风格，翻译成一个能导入的 JSON。
> 文档里的示例配色只是格式演示，**不要抄**。

---

## 0. 先把归属讲清楚

| 谁说了算 | 内容 |
| --- | --- |
| **玩家** | 卡面明暗、冷暖、质感、要不要加纸纹、想让它像什么 |
| **这份文档** | 语义 token 怎么翻成五套皮肤各自的变量、哪些位置的写入不会生效、输出前怎么自查 |
| **插件** | 卡的结构、折叠方式、翻面动效、数字排版——主题碰不到 |

### 0.1 反锚定条款

- 示例里的配色是**格式演示**，不是「推荐风格」。
- 玩家说「我要亮、要干净、别那么暗」→ 就做浅色卡，不要给「深一点的灰」。
- 输出前自查：这套皮和文档示例放在一起，会不会像同一个人做的？会，就是抄。

## 1. 先搞清楚你在改什么

「状态卡」是聊天楼里那张小卡：谁在场、好感多少、Ta 在想什么。
它有五套皮肤，玩家在 **面板 → 外观与阅读 → 楼内状态卡** 里挑一套。
你做的「状态卡主题」是**在这五套之上刷一层颜色**，不改结构、不改文案、不改动效。

| 皮肤 | 内部 id | 长什么样 | 底色倾向（只是现状，不是要求） |
| --- | --- | --- | --- |
| 晨昏票根 | `ticket` | 可撕副券，展开是房间与名册 | 浅米纸 |
| 月氏藏书票 | `book` | 笺纸名札，双面翻转 | 浅米纸 |
| 预言家日报 | `prophet` | 报纸头版，折叠展开，带人物档案 | 浅灰纸 |
| 朱丝栏邸报 | `dibao` | 暗调抄本，点题签展卷 | 暗棕 |
| 少女心绪 | `calista` | 明信片，珠光贝母的底，轻点翻面 | 浅灰粉 / 夜间暗灰粉 |

**重要**：五套皮肤内部用的是不同的变量名（`--t-*` / `--paper-*` / `--mpp-*` / `--db-*` / `--cl-*`）。
你只写一层**语义 token**，脚本负责翻译。所以同一份 JSON 换到别的皮肤上也说得通。

**五套卡的天性是「浅色纸」**（除了邸报和少女心绪的夜间），所以：

- 想给它们做**深色**，是可以的（四层压暗、字提亮），只是会失去一点「纸」的感觉——这是玩家的选择，不是错误。
- 想给它们做**更浅、更干净、更艳**，也完全可以。

## 2. 最高指令（不许违反）

作者定的 UI 铁律，**原文一字不改**：

```
ui布局严格执行：1.禁黑框与#000，靠1-3%微明度4层背景分层；2.输入框聚焦禁描边，加深双环阴影；3.暗色字重全降40；4.流式打字blur(6px)渐显，120ms且字间错开30ms；5.图标下移0.125em对齐；6.数字锁tabular-nums防抖；7.折叠用Grid 0fr→1fr；8.正文开text-wrap:pretty；9.拖拽弹簧1200/80零回弹，点赞380/18微弹；10.复制对勾2.5s自隐。
```

### 逐条落地：这张卡上哪些归你管

| # | 条款 | 在状态卡上体现在哪 | 你（AI）要做的 |
| --- | --- | --- | --- |
| 1 | 禁黑框与 #000，1-3% 四层分层 | 卡面四层纸（`l0..l3`）、发丝线 `hair/hair2` | 四层给全，相邻明度差 1%~3%；不写纯黑 |
| 2 | 输入框聚焦禁描边，双环阴影 | 卡里的「昵称 / 爱称」输入框、折叠按钮 `:focus-visible` | 只管把 `accent` 与卡面底拉开 ≥3:1，环才看得见；**不要**写 outline |
| 3 | 暗色字重全降 40 | 少女心绪夜间把字重 600→360、正文 400→300 | 别碰字重；`ink` 别选过细的浅灰，会发虚 |
| 4 | 流式打字 blur(6px) 渐显 | 卡里的「心声」逐字出现 | **别碰**：JSON 没有动画字段 |
| 5 | 图标下移 0.125em | 卡头的图标与标题基线对齐 | **别碰** |
| 6 | 数字锁 tabular-nums | 好感 / 肉体 / 阶段 / 暗涌 四个数 | 与主题无关，插件已锁 |
| 7 | 折叠用 Grid 0fr→1fr | 票根的副券、日报的头版、邸报的展卷、少女心绪的翻面 | **别碰**：结构行为 |
| 8 | 正文开 text-wrap: pretty | 卡里的心声与近况 | 与主题无关，插件已开 |
| 9 | 弹簧 1200/80 零回弹，380/18 微弹 | 少女心绪的翻面与落位 | **别碰** |
| 10 | 复制对勾 2.5s 自隐 | 少女心绪的复制动作 | **别碰** |

一句话：**你能改「这张卡是什么颜色、贴什么纸」；不能改「它怎么动、怎么排」。**

## 4. `tokens` 与五套皮肤的对应关系

你写左边，脚本翻成右边。**表里没有的，就是那套皮肤没有这个位置，写了也不生效。**

| 语义 | 少女心绪 `calista` | 朱丝栏邸报 `dibao` | 预言家日报 `prophet` | 月氏藏书票 `book` | 晨昏票根 `ticket` |
| --- | --- | --- | --- | --- | --- |
| `l0` 最底层 | `--cl-bg-0` | `--db-l0` | — | — | `--t-bg` |
| `l1` 第二层 | `--cl-bg-1` | `--db-l1` | `--mpp-paper` | `--paper-bg` | — |
| `l2` 第三层（正文） | `--cl-bg-2` | `--db-l2` | `--mpp-paper-2` | `--paper-inner-bg` | — |
| `l3` 第四层 | `--cl-bg-3` | `--db-l3` | — | — | — |
| `ink` 主字 | `--cl-ink` | `--db-fg` | `--mpp-ink` | `--ink-primary` | `--t-ink` |
| `ink2` 次字 | `--cl-ink-2` | `--db-fg-soft` | `--mpp-ink-2` | `--ink-secondary` | `--t-dim` |
| `ink3` 弱字 | `--cl-ink-3` | — | `--mpp-ink-3` | `--ink-poem-trans` | — |
| `hair` 发丝线 | `--cl-hair` | `--db-hair` | `--mpp-hair` | `--divider` | `--t-border` |
| `hair2` 强发丝线 | `--cl-hair-2` | `--db-hair-strong` | `--mpp-rule` | `--frame-border` | `--t-grid` |
| `accent` 强调 | `--cl-accent` | `--db-seal` | `--mpp-seal` | `--ink-seal-bg` | `--t-accent-red` |
| `accent2` 次强调 | `--cl-accent-soft` | `--db-seal-soft` | `--mpp-gold` | `--ink-seal-border` | `--t-accent-stamp` |
| `shadow` 投影 | `--cl-ambient` | `--db-shadow` | `--mpp-shadow` | `--shadow-color` | `--t-ambient-shadow` |

`accent2` 在少女心绪与邸报上落进的是**半透明填充**变量，脚本会自动把实色转成 18% 透明度再写进去——
你只管给实色。

### 4.1 浅色卡与暗色卡，方向是反的

- **浅色向**（票根 / 藏书票 / 日报 / 少女心绪白天）：`l0` 是最亮的纸，`l3` 反而更暗（阴影层）。文字 `ink` 要深。
- **暗色向**（邸报 / 少女心绪夜间）：`l0` 最暗，逐层变亮。文字 `ink` 要浅。

判断方法：`ink` 对 `l2` 的对比度要 ≥ 7:1。浅色卡上意味着 `ink` 是很深的颜色。
**别把暗色的 token 塞给浅色卡**——那不是风格问题，是字会看不见。

### 4.2 `skin` 怎么选

- 玩家说了在改哪张卡 → 写对应 id。
- 玩家没说 → 先用一句话问清「你现在用的是哪张卡」，比给 `any` 靠谱。
- 硬要写 `any`：同一套颜色在浅色卡和暗色卡上不可能都好看，**优先照顾玩家实际在用的那张**。

### 4.3 风格自由度

这张卡的自由度和全局主题一样大，别被「纸」限制住：

- 想更素：四层压到几乎同色（差 1%），靠 `hair` 和字重撑层级
- 想更艳：`accent` 可以很跳，卡面的印、章、标都吃这个色
- 想更冷 / 更暖：整卡色相一起挪，别只挪 accent
- 想做深色：四层压到 8%~20%，`ink` 提到 90%，这套卡依然好看，只是「纸」变成「硬卡」

## 5. 素材（只有少女心绪有槽）

少女心绪这张卡本来就是用实拍素材做的，所以留了三个口子：

| 槽 | 写到哪 | 用途 |
| --- | --- | --- |
| `paper` | `--cl-paper-art` | 整卡的纸（容器底图，最显眼） |
| `nacre` | `--cl-nacre` | 贝扣 / 翻面时的那层珠光 |
| `cover` | `--cl-cover-art` | 书封上的水印（双扇贝） |

```json
"images": {
  "paper": { "src": "data:image/webp;base64,UklGR...", "opacity": 0.8, "blend": "normal" }
}
```

规则：

- 只收 `data:image/(png|jpeg|webp);base64,` 或 `builtin:nacreNight` 这类内置引用，**不收外链**。
- 单张 ≤ 320KB（解码后），合计 ≤ 900KB。
- 素材槽对 `opacity` / `blend` 只是记录，**卡面按原样铺**——真正的明暗关系由 `l0..l3` 决定。
  所以：**换素材之后，四层底色要跟着素材的气质调**，不然纸是暖的、底色是冷的，会很脏。
- 其它四套皮肤**没有素材槽**。给了图会被忽略，并在导入结果里明确告诉你，不会悄悄吞掉。

内置素材（不用额外下载）：

```
builtin:paperDay   builtin:nacreDay   builtin:coverDay
builtin:paperNight builtin:nacreNight builtin:coverNight
```

### 5.1 少女心绪的两个自动行为（知道就行，不用管）

1. **底图会跟着明暗换。** 这张卡的三张底图也是素材。你给的主题如果是深色（`l2` 偏暗），
   而 `images` 里又没给图，脚本会自动换成同批素材的**夜间版**；浅色主题换日间版。
   不这么做的话，「深色主题 + 浅色珠光纸」= 亮卡配亮字，整张看不见。
2. **正面会被重画。** 这张卡的正面是实拍明信片：纸色、四个角的小字、英文名的银箔压印，
   在皮肤里都是写死的。只改变量动不了它们，所以脚本会额外把
   纸面 / 书签条 / 四个小字 / 英文压印 按你的 `l0~l3 / ink` 重画一遍。
   压印的金属感留着，只是颜色换成你的。

其余四套（票根 / 藏书票 / 日报 / 邸报）本来就是变量驱动，改 `tokens` 就够了。

## 6. `night` 字段

少女心绪默认就有昼夜两套（夜里把同一套灰粉压暗）。你可以只给白天的 `tokens`，
让脚本把夜间也刷成同一套；也可以单独给 `night`：

```json
"night": {
  "l0": "#171316", "l1": "#1E181C", "l2": "#251E22", "l3": "#100C0E",
  "ink": "#F3EAEA", "ink2": "#C9B6BA", "ink3": "#B4A9AD"
}
```

`night` 只写你想改的键，其余沿用 `tokens`。

## 7. 输出前自检

1. `format` 是 `"moonstatus/1"`。
2. `skin` 写的是五个 id 之一或 `any`。
3. 四层底**沿同一方向**排（浅色向由亮到暗 / 暗色向由暗到亮），相邻差 1%~3%。
4. 没有 `#000000`、`#000`、`rgba(0,0,0,…)`、`black`。
5. `ink` 对 `l2` ≥ 7:1，`ink2` ≥ 6:1，`ink3` ≥ 4.5:1
   （低于这几条会被脚本自动抬亮，你的设计会被改）。
6. `hair` / `hair2` 是带透明度的 rgba，不是实色。
7. 素材是内联 base64 或 `builtin:`，没有 http 链接。
8. 只输出一个 JSON 对象，没有解释，没有代码围栏。
9. **这套皮的明暗与色温是从玩家的话里来的，不是从示例里抄的。**

## 9. AI 最容易犯的五个错

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| **抄示例的配色** | 所有卡都长一个样 | 从玩家的话里取 |
| 给浅色卡写暗色 token | 暗底暗字，整张看不见 | 浅色卡：`ink` 用深色，`l0` 最亮 |
| 四层写成一样 | 卡面糊成一张纸 | 每层差 2% 明度 |
| `skin` 写了 `calista`，玩家却在用票根 | 看起来「没生效」 | 不确定就先问一句 |
| 换素材不调底色 | 暖纸配冷底，脏 | 素材决定色温，token 跟着走 |

## 10. 导入

1. 面板 → **系统选项** → **外观与阅读** → **楼内状态卡**（先挑一套卡）
2. 点 **状态卡主题**
3. 粘 JSON → **导入并应用**
4. 不满意：点 **还原**

导入时脚本会当场验：纯黑自动染色、对比度不够会把字抬亮、素材槽不存在会明说。
