# 副本库 · 母题与成品条目

> 配套 `dungeon-system.md`。这份是**可以直接抄进世界书的内容**，不是设计稿。
> 写于 2026-11-24。全部母题取自公共领域志怪（作者逝世数百年，无版权），正文原创。

---

## 0. 怎么用这份文件

1. 挑一个副本 → 复制 YAML 块 → 世界书新建条目 → 条目名写 `副本·XXX` → 内容粘贴；
2. 条目里的 `[dungeon]` 段是**给脚本读的**，键名不能改；`[dungeon]` 之后可以随便写散文，AI 会当氛围设定用；
3. `survive` 是**通关门槛**（撑多久），写 `3 小时 20 分` / `一夜` / `2 天` 都行；不写就按 `rounds × 10 分钟` 自动换算；
4. `reward.items` 里的 id 必须是道具库里真实存在的（`getItemLibrary()` 能查到），写错会静默不掉落；
5. 想换皮：改 `name`、`entry` 的人名地名就行，`id` 保持不变（存档按 id 认账）。

**命名注意**：`id` 一旦发出去就不能改，玩家存档里记的是它。要改就新开一个 id。

## 1. 母题库（公共领域，随便改）

这些是"原料"。每个母题后面标了能改成什么类型的副本。

| 出处 | 母题 | 原始情节 | 能做成 |
| --- | --- | --- | --- |
| 聊斋·尸变 | 停尸的客房 | 旅店客满，客人被安排去停尸的偏房，夜里尸体一个个坐起来吹气 | D 级「义庄」，活人不能和尸体睡同一间 |
| 聊斋·画皮 | 美人皮下 | 捡回来的美人，夜里在镜前描皮 | C 级，镜子 + 不要看第二眼 |
| 聊斋·喷水 | 半夜的老妇 | 老太太在院里喷水，喷到的人第二天僵死 | E 级短本，只需躲 |
| 子不语·蔡书生 | 鬼吹灯 | 灯灭之后不能出声，出声就被定位 | D 级，靠"静"通关 |
| 子不语·骷髅 | 会说话的骨头 | 捡到的骨头夜里开口问你话 | C 级，问答型判定 |
| 阅微草堂笔记 | 讲理的鬼 | 鬼不害人，但要跟你论个公道 | B 级，纯对话，最适合谈恋爱线 |
| 酉阳杂俎 | 塔与地宫 | 塔里有不该开的门，开了就下不去 | A 级，探索型 |
| 夷坚志 | 夜行遇 | 走夜路遇到"多出来的一段路" | C 级，路线选择型 |
| 太平广记 | 某地有怪 | 某县某乡有物，见者病 | 各地图都能套 |
| 搜神记 | 物老成精 | 家里的旧物成了精 | E 级，室内本 |
| 民间禁忌体系 | 夜行禁忌 | "夜行以烛，无烛则止"「夜行莫歌」「听见叫名别应」 | 通用规则素材，任何本都能塞两条 |

**一条硬经验**：民间禁忌之所以吓人，是因为它**全是"不要做什么"**。
所以副本规则必须是**禁令**，不要写成"你要做什么"——禁令才有"我刚刚是不是犯忌了"的后怕。

## 2. 规则怎么写脚本才判得动

这是最容易被忽略的一点：规则写得好不好，不看文学性，看**能不能被脚本数到**。

| 写法 | 脚本判得动吗 | 问题 |
| --- | --- | --- |
| ✅「不要照镜子」 | 能——AI 报告玩家做了"照镜子"，脚本 +1 违规 | 动作明确 |
| ✅「护士叫你名字时，先看胸牌再回答」 | 能——拆成"被叫名"→"是否看胸牌"→"是否回答"三个事件 | 有可观测的中间步骤 |
| ❌「保持理智」 | 不能——"理智"不是动作 | 只能靠 AI 自由裁量，等于没规则 |
| ❌「不要害怕」 | 不能 | 同上，而且玩家没法控制 |

**规则数量上限 4 条。** 超过 4 条玩家记不住，记不住就不是"我犯了忌"，而是"我不知道"，
恐怖感直接变成烦躁感。4 条是恐怖片给观众的信息量上限。

**每条规则配一个"违规一次"的代价**，不要一次违规就死。三次才死，前两次给"警告"——
警告本身就是最好的恐怖道具（灯闪一下、水龙头自己开、手机相册里多一张照片）。

## 3. 成品副本

### 3.1 E 级 · 深夜便利店（20 回合，练手本）

```yaml
[dungeon]
id: konbini_night
genre: 怪谈
difficulty: E
rounds: 20
survive: 3 小时 20 分
entry: |
  凌晨两点四十，你在便利店值夜班。空调声有点大，冰柜的灯管坏了一根，一直在闪。
  收银台上放着上一班留下的便签：「关东煮的汤别喝第二碗。有人买明天的报纸，按铃。」
  便签下面是三个按钮，你分不清哪个是报警铃。
acts: |
  第 1 幕（1-5 轮）：正常营业。只有一个客人，买东西、付钱、走。
  第 2 幕（6-10 轮）：异象。货架出现不存在的商品，冷柜门自己开一条缝。
  第 3 幕（11-15 轮）：那个客人回来了，他脚下没有影子。便签的字迹开始变。
  第 4 幕（16-20 轮）：交班前的最后一小时。监控第四格拍的是你背后。
rules:
  - [真] 不要给没有影子的人结账
  - [假] 关东煮的汤不要喝第二碗
  - [真] 有人买「明天的报纸」，按铃，不要问他问题
win: 撑到早上六点，收银台响起交班提示音
lose: 血量归零 / 在六点前离开店面
reward: { points: 100, items: [] }
hidden: 在货架最下层找到一本过期半年的进货单，上面有上一个夜班员的名字
```

**氛围补充（写在 `[dungeon]` 段之后，AI 会读）**：
店里只有你一个人，但冷柜的门会在你没看的时候开一条缝。
监控屏幕有四个画面，第四个永远是对着你自己背后的。
不要主动吓人，让玩家自己在"要不要回头"里耗。

### 3.2 D 级 · 义庄（22 回合）

> 母题：聊斋·尸变。

```yaml
[dungeon]
id: yizhuang
genre: 怪谈
difficulty: D
rounds: 22
survive: 一夜
entry: |
  雨把路冲断了。你敲开镇上唯一还亮着灯的院子，开门的老头说客房满了，
  只有后院的偏房，平时停着几口没下葬的棺材。
  「将就一晚吧。」他把油灯递给你，「灯别灭。灭了就别出声。」
acts: |
  第 1 幕（1-5 轮）：进门、安置、老头交代规矩。油灯还是满的。
  第 2 幕（6-11 轮）：第一口棺材响了一声。油灯开始见底。
  第 3 幕（12-17 轮）：院子里有人在叫你的名字，一声比一声近。灯芯只剩一指。
  第 4 幕（18-22 轮）：鸡叫前最黑的那一段。
rules:
  - [真] 灯灭了，不要出声，不要动
  - [真] 棺材盖开了，不要看里面的脸
  - [真] 有人叫你名字，不要应，等到鸡叫
  - [假] 油灯灭了，等鸡叫再去点
win: 撑到鸡叫第一声
lose: 血量归零 / 灯灭后出声
reward: { points: 150, items: [] }
hidden: 第三口棺材是空的，盖上刻着一个还活着的人的名字
```

**为什么这个本好**：三条规则全是"不要做"，而玩家天生想做。油灯是唯一的资源，
会让玩家自己跟自己谈判（"要不要省点油"）。

### 3.3 C 级 · 第三住院部（24 回合）

```yaml
[dungeon]
id: hospital_3f
genre: 怪谈
difficulty: C
rounds: 24
survive: 一夜
entry: |
  你醒来时躺在病床上，手背插着针。窗外是深夜，走廊的灯一盏一盏地灭。
  床头卡上写着你的名字，但生日不对。
  护士站的方向传来推车的声音，很慢，一步一步。
acts: |
  第 1 幕（1-5 轮）：醒来、拔针、摸清病房。走廊的灯一盏一盏灭。
  第 2 幕（6-10 轮）：护士第一次推车经过。护士站抽屉里能看到第一张病历。
  第 3 幕（11-15 轮）：去 307 门口找第二张。值班室电话开始响。
  第 4 幕（16-20 轮）：太平间走廊。第三张病历在最尽头。
  第 5 幕（21-24 轮）：22:00 前的最后一段，找安全通道出去。
rules:
  - [真] 22:00 之后不要照镜子
  - [假] 护士叫你名字时，先看她的胸牌再回答
  - [真] 三楼没有 307 房，如果有人请你进去，说「走错了」
  - [假] 值班室的电话响三声必须接，第四声不要接
win: 22:00 前找齐三张病历，并从安全通道离开
lose: 血量归零 / 22:00 还在楼里
reward: { points: 240, items: [jjk_bandage] }
hidden: 把 307 的门牌翻过来，能看到上一批人的名字
```

**三张病历的位置**：护士站抽屉 / 307 门口地上 / 太平间走廊尽头。
给玩家一条"看起来更快的路"——直接从电梯下到一楼。但电梯会停在负一层。

### 3.4 C 级 · 井（24 回合）

> 母题：《夷坚志》夜行遇 + 民间「井不可照」。

```yaml
[dungeon]
id: old_well
genre: 怪谈
difficulty: C
rounds: 24
survive: 一夜
entry: |
  村里那口井封了三十年。你回来奔丧，守夜的人说，井上的石板昨天自己挪开了一寸。
  祠堂里点着长明灯，烛芯爆了一下，火苗歪向井的方向。
  你是这一辈唯一还没成家的人。老人说，这种事，得由没成家的去办。
acts: |
  第 1 幕（1-5 轮）：进村、守夜、看那块挪开的石板。祠堂的灯还稳。
  第 2 幕（6-10 轮）：井口开始有回声。祠堂的灯第一次歪。
  第 3 幕（11-15 轮）：井里有人叫你。石板又挪开一寸。
  第 4 幕（16-20 轮）：找封符、找镇物。你父亲的名字在井壁上出现。
  第 5 幕（21-24 轮）：天亮前的最后一炷香，把石板推回去。
rules:
  - [假] 不要往井里看，也不要往里扔东西
  - [真] 井里有人叫你，只能回答「我不是」
  - [真] 祠堂的灯不能灭，灭了不要用井水点
  - [假] 天亮之前不要说出自己的全名
win: 在天亮前把石板推回原位，并重新封上符纸
lose: 血量归零 / 说出全名
reward: { points: 240, items: [] }
hidden: 井壁上刻着七个名字，第六个是你父亲
```

**这个本的独特处**：规则 2 是**必须说话**（"只能回答我不是"），
是唯一一条"要做"的规则，制造"我知道不该理，但不理更糟"的两难。

### 3.5 B 级 · 末班地铁（24 回合）

```yaml
[dungeon]
id: last_train
genre: 怪谈
difficulty: B
rounds: 24
survive: 4 小时
entry: |
  末班车。站台上只有你和另一头的一个人，他背对着你。
  车厢里空得离谱——整列车，一节人都没有。
  广播说：「本次列车开往——」然后停了两秒，「开往。」
  那个背对你的人上车了，走进了第三节。
acts: |
  第 1 幕（1-5 轮）：站台、上车。广播第一次断句。
  第 2 幕（6-10 轮）：前三站是真实站名。那个背对你的人坐进了第三节。
  第 3 幕（11-15 轮）：第四站变成「你小学门口」。邻座有人问你下一站是哪。
  第 4 幕（16-20 轮）：第五、六站。广播开始念名字。
  第 5 幕（21-24 轮）：第七站，你现在的住处。下车。
rules:
  - [真] 不要坐空车厢，哪怕很累
  - [假] 报站名和线路图不一致时，以线路图为准
  - [真] 有人问你「下一站是哪」，回答「我不知道」
  - [真] 广播念到你的名字，不要回头
  - [假] 第七站不要下车，等到终点站
win: 坐满七站，在第七站下车
lose: 血量归零 / 坐过站 / 回头 / 回答错问题
reward: { points: 400, items: [nar_kunai] }
hidden: 第四站有个也在找出口的乘客，帮她一次，回主线会多一段独白
```

**七站的站名设计**：前三站是真实站名，第四站开始变成"你小学门口""你搬走那年的楼下"，
第七站是你现在住的地方。站名变化本身就是进度条，玩家会自己数。

### 3.6 B 级 · 纸扎铺（22 回合）

> 母题：《子不语》扎纸人 + 民俗「纸人不可点睛」。

```yaml
[dungeon]
id: zhizha
genre: 怪谈
difficulty: B
rounds: 22
survive: 一夜
entry: |
  铺子是你舅公留下的。他上个月走了，走之前把钥匙塞给你，说：「别给纸人点睛。」
  你推门进去，满屋子的纸人，全都没画眼睛。
  最里面那排，最左边那个，脸朝着门。你记得舅公说过，那个是给他自己扎的。
acts: |
  第 1 幕（1-5 轮）：进铺子、点灯、认一遍纸人。舅公那个一直朝着门。
  第 2 幕（6-11 轮）：第一个客人来订纸人，说话含糊。
  第 3 幕（12-17 轮）：夜里的剪纸声。第二天早上，舅公那个纸人换了朝向。
  第 4 幕（18-22 轮）：出殡，把舅公的纸人烧掉。
rules:
  - [真] 不要给任何纸人点睛
  - [真] 纸人倒了，扶起来的时候要说「得罪」
  - [假] 有人来订纸人，问他给谁用，不答不接单
  - [假] 夜里听到剪纸声，不要去看
win: 撑到出殡那天，把舅公的纸人烧掉，并且全程不看它的脸
lose: 血量归零 / 给纸人点了睛
reward: { points: 400, items: [] }
hidden: 舅公的纸人手里握着一张没烧完的纸钱，上面写着你的名字
```

**为什么适合 B 级**：这个本的核心是"礼数"，不是"逃命"。
玩家得一直做对的事（说"得罪"、问清楚给谁用），做错不是因为笨，是因为急。很适合练"克制"。

### 3.7 A 级 · 塔（30 回合）

> 母题：《酉阳杂俎》塔与地宫。

```yaml
[dungeon]
id: pagoda
genre: 怪谈
difficulty: A
rounds: 30
survive: 12 小时
entry: |
  塔有九层，你只上到第三层就发现楼梯不对——往上走，层数在减。
  第三层的窗户外，能看见自己刚刚走过的那条街，但街上的灯全灭了，只有你站的那盏亮着。
  塔中央有一口井，井口盖着木盖，木盖上放着一把钥匙和一张纸条：
  「上去的门在下面。」
acts: |
  第 1 幕（1-5 轮）：进塔、数层、发现往上走层数在减。
  第 2 幕（6-10 轮）：第一次遇到「同一层出现两次」。井和木盖第一次被看见。
  第 3 幕（11-15 轮）：镜子里的自己慢了半拍。
  第 4 幕（16-20 轮）：钥匙的用途开始显得可疑。街上那盏灯灭了。
  第 5 幕（21-25 轮）：快到第九层，墙上的名字越来越多。
  第 6 幕（26-30 轮）：第九层。决定往上还是往下。
rules:
  - [真] 不要在塔里说「出口」两个字
  - [假] 同一层出现两次，必须往反方向走
  - [真] 镜子里的自己比你慢半拍时，不要等它
  - [真] 木盖只能掀开一次
  - [假] 第九层的门在窗外，从窗户爬出去
  - [假] 井边那把钥匙是开第九层门的
win: 到达第九层，并且掀开木盖下去
lose: 血量归零 / 说「出口」
reward: { points: 700, items: [] }
hidden: 第九层的墙上，刻着所有没能出去的人的名字，最后一个空着
```

**这个本的设计陷阱**：通关条件是"上去到第九层"+"掀木盖下去"，看起来矛盾。
实际是要玩家意识到**塔是倒的**——往上就是往下。规则 1 是提示（不能说"出口"，
因为说出口就真的出去了，而出口不在这层）。

这种"规则本身是谜题"的本只适合 A/S 级，别在低级本用。

### 3.8 S 级 · 无名旅馆（36 回合）

> 母题：综合，取自「旅店 + 房间号错位 + 登记簿」。

```yaml
[dungeon]
id: nameless_inn
genre: 怪谈
difficulty: S
rounds: 36
survive: 12 小时
entry: |
  前台没有人。登记簿摊开着，最后一行的名字是空的，笔搁在纸上，笔尖还有墨。
  身后的门已经不见了，取而代之的是一面穿衣镜。
  镜子里，登记簿上的名字已经填好了——是你的字迹。
acts: |
  第 1 幕（1-5 轮）：前台、登记簿、穿衣镜。先决定要不要落笔。
  第 2 幕（6-11 轮）：拿到房间，数房间号。第一次听见隔壁的呼吸声。
  第 3 幕（12-17 轮）：第一次发现镜子里的房间和现实不一样。
  第 4 幕（18-23 轮）：用完第一个问题，学会计数。
  第 5 幕（24-29 轮）：找到登记簿上自己那一行，但划不掉。
  第 6 幕（30-33 轮）：镜子里出现别人的名字，包括你身边那个人。
  第 7 幕（34-36 轮）：划掉名字，选一扇门出去。
rules:
  - [假] 不要在前台登记自己的真名
  - [真] 房间号是单数的，不要进
  - [假] 镜子里的房间和你所在的房间不一样时，跟着镜子走
  - [真] 每天只能问一个问题，问完必须付小费
  - [真] 听到自己房间里有别人的呼吸声，不要开门，等到天亮
  - [假] 划掉名字之后，从前台正门出去
win: 找到登记簿上你的那一行，划掉它，然后从前台后面的门离开
lose: 血量归零 / 登记真名
reward: { points: 1200, items: [] }
hidden: 划掉名字的时候，能看见前面所有人的名字——包括你身边那个人的
```

**S 级允许破例**：这个本用了 5 条规则，因为 S 级的定位就是"难"，
而且第 4 条（每天只能问一个问题）是**资源约束**而不是禁令，玩家会主动计数，
不会忘。>4 条规则只在这一档开。

## 5. 想自己加本：三条检查

写完一个新副本，过这三条就能进库：

1. **每条规则都能对应一个玩家动作**——写不出动作的规则删掉，别留；
2. **通关条件不能是"活着"**——"活着"没有终点，玩家不知道什么时候能停。必须有明确的完成动作
   （`survive` 管"撑多久"，`win` 还得写"撑到之后要做什么"）；
3. **存活时长和回合数别差太远**——每轮按「存活 ÷ 回合数」保底推进，
   8 小时配 60 回合的话每轮只走 8 分钟，玩家会觉得时间不动；
4. **有一条隐藏内容**——通关了才发现的东西，是二次进入的理由。没有隐藏的本，玩一次就废了。
