# 旅行道具 · 设计稿（尚未进入游戏）

> 状态：**设计已定，代码未落地**。原因见最后一节「为什么现在做不了」。
> 这份文档是给两条路准备的：① 以后我们做内存级/ROM 级实现；② 拿给改版作者，请他把这五件做进下一版。

---

## 0. 先说一件会改变方案的事

这个改版**自己已经有半套**是这个需求了。它的更新日志原话：

> E. 获得对应徽章解锁障碍物清理功能，精灵不需要在另外学习技能（飞翔、闪光、冲浪、潜水（一定程度）可以被道具替代）！

也就是说：

| 你想要的 | 这一版的状态 |
| --- | --- |
| 拿到徽章就能清障，精灵不必学招式 | **已有** |
| 飞翔 / 闪光 / 冲浪 / 潜水 用道具替代 | **已有**（闪光灯、飞天魔毯等，点了要切一次背包才生效） |
| 居合斩 / 碎岩 / 怪力 / 攀瀑 用道具替代 | **没有** |
| 永久不遇野生宝可梦（可关、有冷却） | **没有**（只有步数制的驱虫喷雾） |

所以真正要做的是**四件补缺 + 一件全新**，不是从零造六件。硬塞一套和游戏既有机制并行的「秘传替代」，只会让玩家面对两套规则。

---

## 1. 命名法：怎么才像原生的

翻一遍这版已有的便利道具，命名有很强的规律，照着套就不会出戏：

- **`XX机`**：老年代步机、女神综合机、追踪道具…… 机械感的工具
- **`XX衣 / XX带 / XX毯 / XX炮台`**：穿戴或摆放类
- **`XX礼盒 / XX礼包 / XX文件 / 手册`**：成批给东西的
- **`XX王冠 / XX徽章 / XX之书`**：剧情信物
- 字数：**2~5 字**，绝大多数是 3~4 字
- 语气：说明文**两行以内**，第一行说是什么，第二行说效果，偶尔带一句作者口吻的吐槽（「强制老化的腿脚继续劳动！」）

**禁止**：`秘传替代·壹`、`HM 工具包`、`通行证 PRO` 这类带着「系统味」的写法——一眼就是后加的。

## 3. 全新道具：驱兽铃

用户原本叫它「永久驱」，这个名字太像系统功能。按原生命名法改成 **驱兽铃**（3 字、器物、和「清净符」同族语感）。

| 项 | 内容 |
| --- | --- |
| 分类 | 重要物品 · 不可丢弃 · 永久 |
| 图标 | 一枚铜铃，铃身刻着三个小点，挂绳是褪色的红 |
| 说明 | 「摇一下，野生的就不会靠近。<br>再摇一下收起来——收起来之后，得等它自己安静下来。」 |
| 获取 | 橙华市 · 道馆门口的老婆婆（**打完第一个道馆**、出门时拦住玩家） |
| 台词 | 「打得漂亮。<br>……我看你一路都在草丛里绕。<br>这铃给你。想赶路的时候摇一下，草丛里那些就不会来烦你；<br>要练级了再摇一下收起来。<br>不过它认生，收起来之后得晾一个钟头——急着再摇，它是不响的。」 |

### 3.1 规则（必须逐条实现）

1. 佩戴即生效：铃在重要物品里，**没有「使用」按钮**，靠开关切状态。
2. 开着时：**野生遇敌概率归零**；训练家对战、剧情触发、定点神兽**不受影响**（这条很关键，否则会卡死剧情）。
3. 手动关闭：点一下 → **弹确认框**（这是用户明确要求的提醒），文案：
   > 「收起驱兽铃？<br>收起来之后要等 1 小时才能再摇响。<br>（要练级、要抓精灵的话，建议先别收。）」
   > 　[ 收起 ]　[ 再想想 ]
4. 关闭后进入冷却 **60 分钟**：冷却期间再点，只显示「铃还没安静下来 · 还剩 43 分钟」，不给开。
5. 冷却跨存档保留（存在存档里，不是浏览器本地），换设备也一样。
6. 铃响着的时候，草丛遇敌判定直接跳过——**不走「踩到才判定」的老路**，否则玩家会看到草丛抖动却没有战斗，反而像 bug。

### 3.2 为什么要冷却

不设冷却，玩家会永远开着，等级跟不上、图鉴抓不全，最后卡在道馆——这比不遇敌更难受。冷却把「赶路」和「练级」分成两种状态，是这枚铃真正的设计点。

## 4. 五个 NPC 的共同要求

- **位置在必经之路上**，不在需要绕路的角落；错过就再也不给，所以每个 NPC 在玩家没满足条件时也要有一句「还不到时候」的话。
- 台词**不超过 4 行**，第 1 行接上一句剧情，最后 1 行才说道具。
- 发放动作要有 **获得道具的音效 + 「得到了 XXX！」**，跟原生一致；不要用自定义弹窗。
- 每个 NPC 只出现一次，拿过之后再说只留一句闲话（「石头敲得动吗？」），不要重复发。
- **不要**在对话里出现「插件」「系统」「作者」这类词。

## 5. 为什么现在做不了（技术边界）

要往这个卡带里加道具，得同时改四样东西：

1. **道具表**：新条目（分类、价格、效果、战场/野外效果函数指针）
2. **名字表与说明表**：这版是全中文自解码的，字符编码是改版自己的字库映射——我们手上没有映射表，写进去就是乱码
3. **发放脚本**：新 NPC 或复用现有 NPC 的事件脚本（脚本字节码 + 文本指针）
4. **野外的秘传检查**：把「队伍里有这招」的判定改成「背包里有这件道具」——这是 **ARM 汇编层**的改动，要往空白区写代码再改跳转

我们手上只有 32 MB 编译产物：仓库里 471 个可读字符串，`MASTER BALL`、`POTION` 这类原始名一个都搜不到，说明全部被本地化重编过。**没有源码、没有字库表、没有符号表**，盲改的风险是坏档、坏 ROM，而且我无法验证「打到联盟不崩」这种几十小时的事。

| 路径 | 做法 | 风险 | 我们能做多少 |
| --- | --- | --- | --- |
| **A. 内存级（外置修改器式）** | 找到 GBA 内存在 wasm 堆里的位置，直接读写：写驱虫计数实现「驱兽铃」、改队伍招式/背包实现其余四件 | 中～高：写错地址会坏档；需要先只读验证 | 全流程都能做，但逆向工作量在 1~2 天，且必须先只读取证 |
| **B. ROM 补丁** | 按上面四步改二进制 | 高：需要字库表与汇编，无法充分回归 | 只能等源码或作者配合 |
| **C. 交给作者** | 把这份设计（尤其是命名、台词、规则）交给改版作者，他手上有源码 | 低 | 已完成——就是这份文档 |
